🎯 DESCRIPCIÓN DEL PROYECTO
═════════════════════════════════════════════════════════════════════════════

Aplicación innovadora para ayudar a jóvenes en Valencia a gestionar su búsqueda
de vivienda, permitiendo registrar, comparar y analizar opciones de alquiler
versus compra con cálculo automático de hipotecas.


🎯 TEMA INNOVADOR
═════════════════════════════════════════════════════════════════════════════

El proyecto aborda el problema REAL de la crisis de vivienda en Valencia,
ofreciendo a los jóvenes una herramienta práctica para:

✓ Comparar opciones de alquiler vs compra
✓ Calcular automáticamente cuotas de hipotecas
✓ Analizar datos visualmente con gráficas
✓ Tomar decisiones informadas sobre vivienda


════════════════════════════════════════════════════════════════════════════════

📊 CARACTERÍSTICAS PRINCIPALES
═════════════════════════════════════════════════════════════════════════════

✓ 4 pestañas funcionales:
  • 📋 Alquileres - Gestión de viviendas en alquiler
  • 🏠 Compras/Hipoteca - Gestión de compras con cálculo automático
  • ⚖️ Comparativa - Visualización lado a lado
  • 📊 Reportes - Análisis gráfico con matplotlib

✓ Programación Orientada a Objetos:
  • Clase padre: Vivienda
  • Clases hijas: Alquiler y Compra
  • Herencia, polimorfismo y métodos abstractos

✓ Persistencia de datos:
  • Almacenamiento automático en JSON
  • Carga al iniciar la aplicación
  • 5 viviendas de ejemplo incluidas

✓ Análisis visual:
  • Gráfica de distribución (Pastel)
  • Precio por m² (Barras)
  • Costes mensuales (Barras)
  • Distribución por habitaciones (Barras)


🚀 CÓMO EJECUTAR
═════════════════════════════════════════════════════════════════════════════

1. Instala las dependencias:
   pip3 install -r requirements.txt

2. Ejecuta la aplicación:
   python3 main.py

3. ¡La interfaz gráfica se abrirá automáticamente!
